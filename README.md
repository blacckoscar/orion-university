# Orion University

Premium public website for Orion University, Togo — built with Next.js and deployed on Vercel.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Video hero, news arch cards, research/education/athletics sections, multi-column footer
- Orion navy / black-glass chrome with orange accents

## Local development

```bash
npm install
npm run dev
```

## Deploy

Connected to GitHub → Vercel. Pushes to `main` build and promote via Vercel Git integration.
